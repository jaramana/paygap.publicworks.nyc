Data

Everything behind this site as plain CSV. Real numbers, not formatted strings, so the files open straight into a spreadsheet or a script without cleaning. Free to reuse with attribution.

Two conventions worth knowing before you open these. Every file has an n column giving the group size and a suppressed column that is TRUE where the group has fewer than 30 people. Suppressed rows keep their identity and headcount but have their statistics blanked, so "too small to report" is distinguishable from "not in the data". Any column named real_ is already inflation-adjusted to the latest fiscal year; plain salary columns are nominal dollars of their own year.

Rebuilding it yourself

The pipeline is five R scripts and an entry point. Clone the repository and run: 

Rscript run.R

The first run downloads about twelve years of payroll data and takes roughly twenty minutes. After that only the newest fiscal year is fetched. Every threshold, the base year for inflation and the suppression floor live in R/00_config.R, so you can change an assumption and rebuild the whole site against it.

Credit NYC Open Data as the source of the underlying payroll. See method and limits before citing anything.
